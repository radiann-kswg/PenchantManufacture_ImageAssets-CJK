# 曜日図柄配色（decal バリアント `weekday`）

日〜土の曜日漢字 7 字に適用する配色。`scripts/build_cjk.py` の `WEEKDAY` 表が実装側の写しで、
変更時は両方を更新する。decal では 塗り = ボディ（フラット）、縁取り = キーライン＋外ハロー、
grain 0。xterm 列は将来の等幅フォント／ターミナル配色用（現時点では未使用）。
