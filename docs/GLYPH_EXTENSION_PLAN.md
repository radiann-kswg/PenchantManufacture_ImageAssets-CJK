## 1. 前提: 等幅・全角メトリクス（2026-09-10 確定）

和文括弧・約物は**等幅設計**を前提とする。数値の正は [AGENTS.md]「等幅メトリクス契約」。

- **字幅**: 半角 496u / 全角 992u（＝半角×2）。1mm = 66.1u（capHeight 661u = 10mm）。
- **縦帯**: 本家の OS/2 win 帯 [−198, 793] を**そのまま**使う（CJK 専用帯は新設しない）。
  かな箱は上端 661u（大文字上端）〜下端 −198u（`y` のディセンダ）= 13mm。
- 括弧類のインクは em の隅（「 は左上、」 は右下）に寄るのが和文組版の流儀。現行の
  `extract_ai_glyphs.py` は横をインク中央寄せするため、括弧を足す段階で `GRID` に
  **ブロック単位の「隅寄せ（アートボード上の位置を保持）」フラグ**を追加する。
  余白を切り詰めず **枠全体をデカールのフレームとして保持**する点は現行どおり
  （Misskey の幅可変表示で全角幅が意味を持つ）。

## 3. 和文約物（将来候補・未確定）

括弧と同じ全角契約で作れる基本約物。需要が確認できたら §2 と同形式で表を確定する。
候補: `、`(U+3001) `。`(U+3002) `・`(U+30FB) `ー`(U+30FC) `〜`(U+301C) `々`(U+3005)。
トークンは `j` 接頭の語トークン（例 `jten` `jmaru` `jnkdot`）とし、
本家のトークン衝突規則（`n`+数字 / `l`・`u`+1字 / `c`+ギリシャ名 / `y`+翻字を避ける）を順守。

## 4-2. 収録スコープ（2026-09-14 確定）

本リポジトリの収録対象は **7 カテゴリ**（1 平仮名／2 片仮名／3 記号／4 漢数字／
5 カレンダー用漢字／6 干支／7 方角）に分類できる字に限定する。正は [AGENTS.md]「収録スコープ」、
実装は `scripts/extract_ai_glyphs.py` の `SCOPE_SYMBOL` / `SCOPE_KANJI` / `scope_of()`。

- §2・§3 の和文括弧・約物は **カテゴリ 3（記号）** として収録する。
  `ー`(U+30FC) だけは片仮名ブロックなのでカテゴリ 2 扱い（`SCOPE_SYMBOL` には入れない）。
- カテゴリ 4〜7 の字は未着手。原本 `.ai` のアートボード2 に新ブロックを置き、
  `GRID` の行文字列を足す段階で `SCOPE_KANJI` の字種表と突き合わせる
  （表外の字を行文字列に入れると import 時に `SystemExit`）。
- 字種表そのものを広げるときは AGENTS.md・README・本書を同じコミットで更新する。

## 5. 実装メモ

- ソースは **Illustrator 原本 `.ai` のアートボード2**（[AGENTS.md]「CJK グリフの制作フロー」）。
  括弧・約物もアートボード2 に新ブロックとして置き、`extract_ai_glyphs.GRID` に行文字列を足す。
  旧 Fusion → DXF 経路は代替として温存。フォント OTF に CJK が収録された時点で本家同様の
  extract 経路へ切り替える。
- 生成物の命名は本家準拠: かな・約物は AGL 名が無いため `char_uniXXXX_XXXX` 形式。
- 曜日漢字（日〜土）の配色バリアント `weekday` は `docs/WEEKDAY_COLORING_PLAN.md` が正
  （`scripts/build_cjk.py` の `WEEKDAY` 表と同期させる）。
